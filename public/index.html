How This Project Was Engineered

Designed from first principles as a high-throughput, asynchronous media processing workstation. Every layer of the stack was hand-crafted to balance compute efficiency with an uncompromising user experience:

⚡

Asynchronous Stream Ingestion

Decoupled Node.js microservice architecture with non-blocking child process supervisors, handling high-bitrate media parsing without locking the main event loop.

🎛️

Dynamic FFmpeg Muxing Pipeline

Precision multi-stream muxing engine that dynamically captures adaptive 4K video streams (VP9/AV1/H.264) and high-fidelity audio (Opus/AAC 320k) and re-packages them seamlessly into standard MP4/MP3 containers.

📡

Reactive SSE Telemetry Protocol

Sub-millisecond Server-Sent Events (SSE) pipe pushing frame-accurate progress, instantaneous network transfer speeds (MB/s), and real-time ETA estimates directly to the interface.

🎨

Cyber-Aurora Design System

Hand-tuned CSS design token system leveraging glassmorphic backdrops, ambient gradient blurs, custom typography, and zero-dependency micro-animations for responsive, 60fps rendering.

High-Level Data Flow & Processing Pipeline

01
URL Ingestion & Sanitization

Client validates and passes URL to POST /api/info. The engine parses cryptographic stream manifests without invoking heavyweight browser engines.

02
Adaptive Format Negotiation

Backend queries adaptive DASH and HLS playlists, intelligently selecting optimal video/audio stream pairs matching the user's resolution selection.

03
Parallel Extraction & FFmpeg Muxing

Downloader coordinates multi-threaded stream ingestion, feeding video and audio pipes directly into an embedded FFmpeg muxer with zero generational quality loss.

04
Live Telemetry & Direct Client Save

SSE connection (/api/progress/:taskId) streams real-time telemetry. On completion, the binary stream is dispatched via native browser download directly to client storage.
